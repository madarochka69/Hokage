# Симулятор межпланетной миссии (`ares_project`)

**Симулятор межпланетной миссии** — это консольное приложение на Python, моделирующее межпланетный перелет космического корабля. Программа сочетает в себе реальные законы физики (расчет расхода топлива по формуле Циолковского) и текстовый игровой процесс с симуляцией случайных космических происшествий.

---

## 🛠 Структура проекта

```text
ares1/
├── mission/
│   ├── __init__.py    # Инициализация пакета и экспонирование функций
│   ├── physics.py     # Математические расчеты (Delta-V, время, топливо)
│   └── events.py      # Генерация случайных событий с весовыми коэффициентами
├── README.md          # Документация проекта
└── run_mission.py     # Главный скрипт запуска симуляции полета
```

## 🚀 Функционал и модули

### 1. Физические расчеты (`mission/physics.py`)
Модуль отвечает за математическую точность симуляции полета:
*   `delta_v(m0, m1, isp)` — вычисляет необходимую скорость изменения вектора движения космического аппарата по формуле Циолковского.
*   `flight_time(distance_km, accel)` — рассчитывает время перелета в часах с учетом разгона до середины пути и последующего торможения.
*   `fuel_needed(m_dry, target_dv, isp)` — рассчитывает массу топлива, необходимую для достижения заданной \(Delta-V\).

### 2. Игровые события (`mission/events.py`)
Реализует генерацию случайных суточных происшествий с использованием взвешенных вероятностей (`random.choices`):
*   💥 **Микрометеоритный удар:** -15% ресурса *(шанс 40%)*
*   ☀️ **Солнечная вспышка:** -10% ресурса *(шанс 20%)*
*   🛠 **Коррекция курса:** +5% ресурса *(шанс 20%)*
*   📦 **Поиск запасов:** +20% ресурса *(шанс 10%)*
*   ❄️ **Отказ системы охлаждения:** -25% ресурса *(шанс 10%)*

### 3. Планировщик и интерфейс (`run_mission.py`)
Ядро симулятора, управляющее логикой выполнения:
*   Разбор аргументов командной строки через встроенный модуль `argparse`.
*   Посуточный расчет симуляции с использованием планировщика событий `sched.scheduler`.
*   Динамический вывод текстовой гистограммы (progress bar) текущей прочности/ресурса корабля в консоль.
*   Автоматическая экстренная отмена (`s.cancel`) оставшихся задач в очереди при полном исчерпании ресурса корабля (0%).

## 💻 Инструкция по запуску

Для корректной работы скрипта необходимо активировать ваше виртуальное окружение `.venv` и находиться в корневой директории лабораторной работы (`practice`).

### Команда запуска
Запустите симуляцию, передав параметры длительности, зерна генератора (seed) и скорости шага:

```bash
python ares1/run_mission.py --days 6 --seed 42 --speed 0.05
```

### Параметры командной строки:
*   `--days` — общая длительность полета в сутках *(по умолчанию: `5`)*.
*   `--seed` — целочисленное значение для воспроизводимости псевдослучайных событий.
*   `--speed` — реальное время задержки в секундах, соответствующее одним суткам полета *(по умолчанию: `0.2`)*.
